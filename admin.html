Buka & Edit Data Grafik yang Sudah Ada di Google Sheet:

Salin isi sel kolom data_json dari Google Sheet Anda dan tempel di bawah ini untuk memuatnya kembali ke tabel input editor.

Tabel Data Periode & Angka 0 baris

Copy 2 kolom (Kolom 1: Nama Bulan/Wilayah, Kolom 2: Angka Nilai) di Excel, lalu Ctrl+V di bawah ini:

# Periode / Label (Bulan / Tahun / Wilayah) Nilai Data (Angka) Hapus
Tip: Bisa gunakan koma (2,85) atau titik (2.85) untuk desimal.

Hasil Siap Salin ke Google Sheet
Cara Penggunaan di Google Sheet:
  1. Klik tombol biru "Salin Kode data_json" di atas.
  2. Buka Google Sheet, pilih tab visualizations.
  3. Cari baris visualisasi yang ingin diperbarui, klik dua kali pada sel kolom data_json.
  4. Tekan Ctrl + V (Paste) lalu tekan Enter. Selesai!

💡 Tips Pengisian Data
  • Kolom status diisi published agar tampil di portal, atau draft untuk disembunyikan.
  • Kolom featured diisi TRUE untuk menampilkan badge "Unggulan".
  • Kolom file_url diisi dengan link sharing Google Drive (klik kanan file → Share → Copy link).
  • Kolom tags diisi dengan kata kunci dipisah koma: kemiskinan, NTB, 2024.
  • Untuk data_json di tab visualizations, gunakan format Chart.js JSON standard.
Keamanan Password
Password admin tersimpan di file js/config.js. Ganti nilai ADMIN_PASSWORD dengan password yang kuat. Sistem ini menggunakan autentikasi client-side — cocok untuk proteksi ringan, bukan untuk data sangat sensitif.
